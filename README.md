# Machine Learning on Taxi Trip duration
The repository is a project that aims to use different machine learning algorithms/approaches to predict the trip duration of yellow taxis in NYC, using weather and taxi data from 2016.

## Data
The data used in the project is available for download via the repository [MyFirstDataPipeline](https://github.com/SamuelMarEs/MyFirstDataPipeline). 
The exact instructions for the downloading of the data are contained in the README of the repository.
